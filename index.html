Projects I’m Most Proud Of

PokeChamps — Pokémon Team Builder & Analyzer

Click for demo

PokeChamps is a Pokémon team-building web app built with Vue 3 and TypeScript. It allows users to explore Pokémon, build teams, and analyze weaknesses based on type matchups. The app is installable as a PWA, works offline via service workers, and uses browser APIs like notifications and vibration. Teams are stored locally using localStorage, allowing users to persist their data without a backend.
